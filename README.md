# Element Car Care

A modern, responsive, and high-performance landing page designed for **Element Car Care**, a professional automotive detailing studio. Built with clean code and minimalist aesthetic standards, this web application showcases detailing services, service add-ons, pricing, and an interactive portfolio gallery.

---

## Key Features

* **Interactive Portfolio Gallery:** Modal viewer built with vanilla JavaScript that allows users to tap/click any portfolio thumbnail to view full-resolution work (paint correction, wheel detailing, interior restoration).
* **Dynamic Service Add-ons:** Visual comparison cards with custom badge styling for specialized treatments (e.g., *Headlight Restoration* with Before/After previews & *Leather Care*).
* **Minimalist Brand Identity:** Custom HTML/CSS logo badge (`ECC`), sleek dark-mode palette, and high-contrast typography.
* **Direct Booking Call-to-Action:** Integrated WhatsApp action buttons for seamless service scheduling.
* **Fully Responsive:** Optimized layout across mobile, tablet, and desktop devices.
* **Custom Favicon Integration:** Branded tab icon for enhanced web presence.

---

## Tech Stack

* **HTML5:** Semantic markup, accessibility-focused layout, and custom modal overlays.
* **CSS3:** Custom properties (variables), Flexbox, CSS Grid, smooth transitions, and responsive media queries.
* **JavaScript (ES6+):** Light, DOM-manipulation script for handling modal lifecycle (open, close, overlay backdrop tap dismiss).
* **FontAwesome:** Scalable iconography for action buttons and navigation links.
